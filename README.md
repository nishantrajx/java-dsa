# Striver A2Z DSA — Java

My Java implementation and learning repository for the **Striver A2Z DSA roadmap**.

- Understand common problem-solving patterns
- Write clean and readable Java

## Solution Format

Each solution aims to include:

- Problem name
- A2Z section and subsection
- Difficulty
- Problem links when available
- Approach
- Time complexity
- Space complexity
- Key learning

Solutions are written in **Java**.

For easy problems, the explanation stays concise. For medium and hard problems, notes may also include brute force, why it is insufficient, the optimal approach, edge cases, and key mistakes.
